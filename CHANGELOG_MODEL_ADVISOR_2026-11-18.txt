NEXO AI — MODEL FINDER & ASSISTANT
18 November 2026

MODELS
- Expanded the model selector budget ceiling to USD $3/M input and $16/M output when Puter publishes verifiable prices. This makes models such as GPT-5.4 and Claude Sonnet eligible when the account catalogue actually exposes them at or below that ceiling.
- Automatic selection still sorts by catalog cost first and chooses the lowest-cost compatible model; it does not automatically prefer a more expensive GPT-5.4 or Sonnet merely because of the name.
- Cost labels now distinguish very low, low, moderate and elevated published rates. Free variants remain subject to provider quotas; GPT-6 Astra, Claude Opus, Qwen and priority variants stay excluded.
- The dropdown continues to use real model IDs and pricing metadata from puter.ai.listModels(), not invented hardcoded availability.

MODEL ADVISOR
- Added a dedicated Asistente de modelos button and a separate overlay chat that does not modify the main Nexo conversation.
- Advisor history is stored separately in this browser and can be cleared independently.
- The advisor uses the cheapest available eligible chat model, a short recent context and a 240-token output cap.
- Added starter prompts for HTML/web development, image generation, economical model discovery and GPT-5.4 vs Claude Sonnet comparisons.
- The advisor distinguishes chat models from image-generation tools and directs image creation to Nexo's dedicated image generator.

RESPONSIVE / RELEASE
- Added mobile-safe overlay layout, independent scroll region and 16px mobile composer text to avoid iOS input zoom.
- Bumped the service-worker cache key so deployed clients can fetch the updated release.

NOTES
- Eligibility does not mean a model is cheap. GPT-5.4 and Sonnet may be labelled moderate/elevated; actual Puter catalogue rates and account quotas take precedence.
- Pricing per million tokens is not a prediction of a whole conversation's cost. Input, output, history, images and tools also affect usage.
- No live Puter account or interactive browser session was available for this static build check.
