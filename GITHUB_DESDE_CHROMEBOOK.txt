SUBIR NEXO AI DESDE CHROMEBOOK

1. Descarga el ZIP y ábrelo en la app Archivos. Extrae el contenido.
2. En GitHub, abre el repositorio y pulsa Add file → Upload files.
3. Selecciona los archivos extraídos. Si no acepta carpetas, sube los archivos sueltos y crea `icons/` y `api/` para colocar su contenido.
4. Conserva `index.html` en la raíz del repositorio y `api/read-url.js` dentro de `api/`.
5. Pulsa Commit changes.
6. En Vercel importa el repositorio. Usa Framework Preset Other, sin Build Command y Output Directory `.`.
7. Despliega. Cuando esté en Ready, abre la URL HTTPS e inicia sesión con Puter.

No subas el ZIP como único archivo. No subas nunca un `.env` real ni claves privadas. Nexo no incluye pagos ni necesita configurar Stripe o Supabase.

Para activar la versión nueva, recarga con Ctrl+Shift+R. Si usas la PWA, ciérrala completamente y vuelve a abrirla.
