SUBIR NEXO AI 7.4 — PAPOI 8 CREATOR ENGINE DESDE CHROMEBOOK

1. Descarga el ZIP y ábrelo en la app Archivos. Extrae el contenido.
2. En GitHub, abre el repositorio y pulsa Add file -> Upload files.
3. Pulsa “choose your files” y selecciona los archivos normales desde la carpeta extraída. Si no acepta carpetas, sube archivos sueltos y después crea los directorios `icons/` y `api/`, subiendo dentro sus archivos correspondientes.
4. Conserva `api/read-url.js` dentro de `api/` y los iconos dentro de `icons/`.
5. Pulsa Commit changes.
6. En Vercel importa el repositorio. Usa Other, sin build command y Output Directory `.`.
7. Despliega y prueba la URL HTTPS.

No subas el ZIP como único archivo. `index.html` tiene que estar en la raíz del repositorio.
