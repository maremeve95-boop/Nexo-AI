NEXO AI 7.4 — PAPOI 8 CREATOR ENGINE

QUÉ INCLUYE
- Papoi 8 prioriza modelos reales actuales de OpenAI/GPT/Codex o Claude Sonnet disponibles en el catálogo de Puter.
- No se usa Qwen. Claude Opus sigue reservado para los perfiles bloqueados Nexo 5.5/6.
- Crea HTML y juegos web y convierte los archivos generados en enlaces de texto clicables, botones de descarga y ZIP si hay varios archivos.
- Mantiene lectura web, adjuntos (incluidos HTML y ZIP), historial, memoria local y la PWA para ordenador/móvil.

PUBLICACIÓN CON GITHUB + VERCEL
1. Descomprime el ZIP.
2. Sube TODO el contenido a la raíz del repositorio GitHub, incluidos `index.html`, `api/`, `icons/`, `manifest.webmanifest`, `service-worker.js` y `vercel.json`.
3. En Vercel importa el repositorio.
4. Selecciona Framework Preset `Other`; deja Build Command vacío y Output Directory `.`.
5. Pulsa Deploy y abre la URL HTTPS generada.

NOTAS
- Papoi 8 es un perfil especializado, no un modelo neuronal entrenado desde cero.
- La app elige dinámicamente modelos del catálogo; no inventa disponibilidad. Si no hay un modelo Claude Sonnet/OpenAI permitido, actualiza el catálogo o cambia de perfil.
- Los proveedores externos pueden tener cuotas. No se promete uso ilimitado.
- No subas claves privadas a GitHub ni a archivos HTML públicos.
