NEXO AI 8.1.1 — PREMIUM OPCIONAL Y CRÉDITOS

Esta versión incluye una cartera de créditos propia preparada con Supabase + Stripe y un endpoint de IA en servidor. Los pagos están desactivados hasta configurar todas las variables y el webhook; el ZIP no contiene claves ni productos de Stripe.

ACTUALIZAR EN GITHUB + VERCEL
1. Descomprime el ZIP.
2. Sube todo el contenido a la raíz del repositorio, manteniendo index.html, api/, lib/, supabase/, icons/, manifest.webmanifest, service-worker.js y vercel.json.
3. Haz commit y espera al despliegue de Vercel.
4. No subas un archivo .env real. Usa Vercel -> Settings -> Environment Variables para los secretos.

ACTIVAR CRÉDITOS REALES (OPCIONAL)
Lee PAYMENTS_SETUP_ES.md antes de habilitar Stripe. Primero usa claves y productos de prueba. Ejecuta supabase/SUPABASE_SETUP.sql, configura precios/ webhook, variables de entorno, y prueba pagos, entregas de créditos y reembolsos antes de pasar al modo live.

IMPORTANTE
- El saldo Nexo no recarga la cuenta de Puter. La cartera Nexo paga el uso de la API de IA configurada en el servidor.
- Las credenciales privadas viven solo en variables de entorno de Vercel, nunca en el HTML o el repositorio.
- Los endpoints /api/ se excluyen de la caché del service worker.
- El código se ha comprobado por sintaxis y estructura; valida toda integración de pagos en modo test antes de usar dinero real.
