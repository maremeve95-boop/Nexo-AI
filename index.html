Protección inteligente de créditos

Cuando el uso mensual se acerca al límite, Nexo reduce automáticamente las respuestas normales y evita revisiones extra. No cambia el modelo que has elegido ni bloquea tu chat.

Ahorro inteligente
Activo por defecto: desde el 80 % reduce tokens; desde el 90 % limita todavía más y desactiva el razonamiento extra.

La protección solo actúa cuando el medidor real de Puter está disponible.

Qué influye en el consumo

Influyen el modelo real, los tokens de entrada y salida, el historial, las búsquedas auxiliares, el análisis de imágenes y las revisiones adicionales. Nexo prioriza modelos con tarifas verificadas, limita el historial y mantiene desactivadas las segundas revisiones de código por defecto.

Desglose del consumo por API

Puter puede tardar alrededor de un minuto en reflejar el detalle por API o por aplicación. El consumo mensual y los créditos disponibles son la referencia principal; el dato detallado puede tardar un minuto.

Historial de uso

El consumo mensual y los créditos disponibles se consultan al actualizar el panel. El detalle por API puede tardar alrededor de un minuto. La API no devuelve la fecha exacta del próximo reinicio; consulta el ciclo de tu cuenta en el panel oficial.
